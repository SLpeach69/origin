Проект состоит из двух программ

Программа "Паук" (pauk)
Для обхода сайтов и индексация содержимого
Сканирует сайты, начиная с указанного в data.ini
Сохраняет слова и их частотность в PostgreSQL
Многопоточный обход с ограниченной глубиной 

Программа-поисковик (server)
Веб-сервер для поиска по индексированным данным
Веб-интерфейс для поисковых запросов
Ранжирование результатов по релевантности

Все настройки в файле data.ini:

В базе будет две таблицы  
Первая - ссылки на сайты
Вторая - слова и маркер на первую таблицу
